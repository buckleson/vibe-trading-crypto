# T03 tests: design tokens, UI primitives and app shell

All tests are vitest and run in jsdom. They are offline and deterministic: no network, no backend and no Anthropic SDK.
The mocks are `@/lib/api`, `@/stores/agent`, `@/hooks/useDarkMode`, `sonner`, and the lazy dock panels `ChatPanel`, `TerminalPanel` and `WalletButton` (shell file only).
Static checks read `frontend/src/index.css`, `tailwind.config.ts`, `index.html`, `public/theme-boot.js`, `public/*.svg`, `assets/icon.svg`, `assets/icon.png`, `router.tsx` and `cook/BRIEF.md` from disk. No implementation code was changed.

## Findings while testing (no implementation change made)

- Home nests `<Button>` inside `<Link>` (a `button` inside an `a`), and uses `tabIndex=-1` so keyboard users see one stop. This is invalid interactive nesting in HTML. A later page wave could render the Link with button classes instead. The tests assert the link target and the single primary button, not the nesting.
- `navigation.groups.trade` is not in en.json, so the section label comes from `defaultValue: "Trade"`. The locale sync task should add it.
