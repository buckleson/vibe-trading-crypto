# T01 tests: rebrand to Vibe Crypto

All tests are offline and deterministic. They make no network calls and never touch a real
Anthropic key or exchange. Some checks compare against the imported upstream baseline commit
`d19d1ac` ("Import upstream HKUDS/Vibe-Trading @283e300") to prove that internal identifiers and
attribution text were not changed. Set `T01_BASELINE_REF` to use a different ref. These checks
skip when git or the ref is unavailable. Because the ref is pinned, they stay valid after the
rebrand is committed.

## Commands

```
cd /home/user/vibe-trading-crypto && . .venv/bin/activate && python -m pytest agent/tests/vibe_crypto/test_T01.py -q
cd /home/user/vibe-trading-crypto/frontend && npx vitest run src/__tests__/vibe-crypto/T01.rebrand.test.tsx
cd /home/user/vibe-trading-crypto/desktop/electron && npm run build && node scripts/test-rebrand-T01.mjs
```
