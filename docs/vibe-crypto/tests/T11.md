# T11 tests: cross-platform Electron app and embedded Claude terminal

All tests are offline and deterministic. No Electron window, real PTY, `claude` process, exchange or Anthropic API is used.

## How to run

```
cd /home/user/vibe-trading-crypto/desktop/electron && npm run build && node scripts/test-T11.mjs
cd /home/user/vibe-trading-crypto/frontend && npx vitest run src/__tests__/vibe-crypto/T11.terminalPanel.test.tsx
```

Regression (developer-written) checks:

```
cd /home/user/vibe-trading-crypto/desktop/electron && node scripts/test-backend-resolution.mjs && node scripts/test-locales.mjs && node scripts/test-terminal.mjs && node scripts/test-packaging-preparation.mjs && node scripts/test-update-safety.mjs
cd /home/user/vibe-trading-crypto/frontend && npx vitest run src/components/terminal && npx tsc -b
```

`test-T11.mjs` prints a JSON map of check name to `ok` / `FAIL: ...` and exits 1 on any failure. It loads `../dist`, so build first. node-pty is replaced by a fake module via a `Module._load` hook, so no native build is needed.

## frontend/src/__tests__/vibe-crypto/T11.terminalPanel.test.tsx (26 tests)

- terminalAvailable: false in browser, false without `terminal`, false with `terminal: undefined`, true with the API.
- Without the API: empty state, no xterm instance, no Restart button.
- Header copy and Restart button; xterm options (font, size 13, cursorBlink, allowProposedApi false), FitAddon loaded, opened in a div, fit called.
- start called once with fitted cols/rows; still starts when the first fit throws.
- Input forwarding verbatim (control bytes, escape sequences, empty string, unicode); output written in order; exit notice for codes 0 and 137.
- ResizeObserver refits and calls `terminal.resize`; no resize when fit throws.
- Restart: kill before start, screen cleared, current size, no new xterm; waits for the kill promise before starting.
- Unmount: offData/offExit/input dispose/xterm dispose/ResizeObserver disconnect, kill not called; remount reattaches.
- Theming: CSS tokens converted to hex (`#ffffff`, `#ff0000`, `#0000ff`, selection `#0000ff4d`), fallbacks are valid hex, re-themes on `dark` class toggle, stops re-theming after unmount.
- Source hygiene: xterm CSS import, exactly one `.kill(` call (Restart), no em dash / uppercase / gradient / purple / beige, xterm package versions.
