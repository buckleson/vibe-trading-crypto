# T08 tests: page redesign A (Agent, RunDetail, Compare, Reports, chat and run components)

All tests are vitest in jsdom. They run offline and give the same result every time: there is no network, no backend and no Anthropic SDK.
- `@/lib/api` is mocked in every rendered file. `T08.agentPage` also mocks `@/hooks/useSSE`.
- `sonner` is mocked.
- Chart components owned by T10 (`EquityChart`, `CandlestickChart`, `FactorResearchPanel`, `StrategyResearchDashboard`) are stubbed in `T08.runPages`.
- `T08.bannedPatterns` reads source files only.

No implementation code was changed.

## Results (2026-11-14)

- **T08 files:** 116 tests, 114 pass and 2 fail. Repeated runs gave the same result.
- **The 2 failures are real defects in `frontend/src/pages/Compare.tsx`.** Lines 23 and 54 return `"—"`, an em dash, as the placeholder for a missing metric and for a missing delta. The Compare results table therefore shows an em dash in the UI. That breaks the BRIEF slop ban, and it contradicts the handoff claim that the placeholders were changed to "-". The literal-character grep misses it because the source uses the escape sequence. The fix is to return `"-"` in both places.
  - `T08.bannedPatterns > no escaped em dash or &mdash; that renders as an em dash in the UI`
  - `T08.runPages > T08 Compare page > missing metrics render a placeholder that is not an em dash`
- **Developer tests** in the spec's step 7 paths: 33 files and 211 tests, all pass.
- **`npx tsc -b`:** clean.
- **Full `npx vitest run`:** 119 files and 1659 tests, with 3 failures. Two are the Compare failures above. The third is the existing T05 hero-number failure, which T08 does not own.

### Fixes to the T08 test files (test bugs, not implementation)
- **Reports `beforeEach`.** It returned `mockReset()`'s value, and vitest runs a function returned from a hook as teardown. That called the rejecting `listRuns` mock after the test and surfaced as "Error: boom". The hook now uses braces.
- **RunDetail total return.** `MetricsCard` splits the value into a glyph span, the text and an sr-only verdict, and formats it as `+25.00%`. The test now matches on the `<p>` text content.
- **Reports status Badges.** "failed" also appears as an option in the status filter `<select>`. The query is now scoped to the table.

### Spec gap (not asserted)
Step 3 asks for drawdown to be shown as neutral. RunDetail reuses `MetricsCard`, which colors `max_drawdown` by threshold through `metricSentiment` in `lib/formatters`, a file T08 does not own. No test asserts this, so it is a review item.

## Test cases

### `T08.bannedPatterns.test.ts` (static audit of the owned source)
- **Owned set.** It covers Agent, RunDetail, Compare and Reports, every `components/chat/*.tsx` and every `components/run/*.tsx`, and excludes tests.
- **Zero hits for each banned pattern:**
  - the `uppercase` class and `tracking-wider`/`tracking-widest`
  - `font-serif`
  - gradient backgrounds and gradient stops
  - `shadow-*` glows
  - `animate-pulse` and `animate-ping`
  - literal em dashes
  - `rounded-xl`, `rounded-2xl` and `rounded-3xl`
  - `text-[8-11px]`, `text-2xs` and `text-xxs`
  - `blur-2xl`, `blur-3xl` and `backdrop-blur`
- **Escaped em dashes.** No `—`, `&mdash;` or `&#8212;` (**fails: Compare.tsx**).
- **No emoji, counters or raw palette colors:**
  - no emoji pictographs
  - no 01/02/03 counters or `padStart(2,"0")` numbering
  - no purple, violet, fuchsia or indigo utilities
  - no raw Tailwind palette colors (emerald, amber, sky and so on); tokens only
- **Raw hex.**
  - Only Compare.tsx and PositionsTab.tsx contain hex literals.
  - The Compare hex values are exactly the `--chart-compare-a/b` fallbacks.
  - The PositionsTab palette has no purple, magenta or pink hue (255 to 345 degrees) and no beige or tan.
- **Layout contracts in source:**
  - Agent has no `<Page>` and has at least two `max-w-3xl mx-auto px-4` columns.
  - RunDetail uses `<Page width="wide">` in at least 3 states, plus PageHeader, Tabs and the `from_run=${encodeURIComponent(runId)}` link.
  - Compare and Reports use Page, PageHeader and `<Table>`, with no raw `<table>` in the pages or run components.
  - WelcomeScreen uses `text-xl font-semibold`, a 13px muted subtitle and `sm:grid-cols-2`.
  - MetricsCard and RunCompleteCard import from `@/components/ui`.
  - Composer uses the ui Button inside a `rounded-lg bg-card` container.

### `T08.runPages.test.tsx` (RunDetail, Compare and Reports rendered)

**RunDetail: the "Run on paper" link**
- A successful run gets an href of `/paper-trading?from_run=run-1`. The link uses the primary classes and `rounded-md`, and has an aria-hidden svg icon.
- Run ids are encoded and round-trip through `URLSearchParams`. Cases: spaces with `&?#`, `/`, CJK characters and `+=`.
- These states show the link:
  - failed with an equity curve
  - cancelled with an equity curve
  - success with an empty curve
- These states hide it:
  - failed or cancelled or running with no curve
  - failed with an empty curve
  - an empty status with an empty curve
- Clicking the link navigates to `/paper-trading?from_run=nav-1`.
- No link appears while loading.
- Not found shows an EmptyState with a Go back action and no link. `getRun` resolving `null` is treated as not found.

**RunDetail: header, metrics and tabs**
- **Header.**
  - There is a single h1.
  - The run label is the sentence-case mono text "Run <id>", with no uppercase and no "RUN".
  - The status is announced as sr-only text: Completed, Failed or Cancelled.
- **Description.** It shows codes and the date range "2024-01-01 to 2024-06-30".
- **Export buttons.** They appear only when there are metrics or trades. They are not primary, and they sit in the wrapping action row beside the link. There are no export buttons when the run has neither.
- **Total return** is colored by sign: `+25.00%` is success and `-10.00%` is danger.
- **Tabs.**
  - The tablist is labelled "Run sections" and sections without data are hidden.
  - Tearsheet appears only when there is an equity curve.
  - The arrow keys move the selection.
  - The Code tab with no files shows an EmptyState.
- **Trades table.** It scrolls inside an `overflow-x-auto` wrapper.
- **Long prompt.** It clamps and expands.

**Compare**
- It has a page heading, plus labelled Baseline and Compare selects.
- With no runs it shows an EmptyState, no table and no `getRun` calls.
- When `listRuns` fails, it shows a toast and keeps the EmptyState.
- Swap exchanges the two selections.
- The results table uses Table primitives, with right-aligned `tabular-nums` numeric columns.
- **Missing metrics render no em dash (fails).**

**Reports**
- Reports are listed in a Table that scrolls inside its own wrapper. Numeric cells are right-aligned and `tabular-nums`, colored success or danger by sign. Zero and NaN are neutral, and the placeholder is "-".
- Status Badges render in the table. An unknown date falls back to the raw string, and a report with no prompt shows "No prompt recorded.".
- The status filter narrows the rows and updates "1 of 3 reports".
- A search with no matches shows the no-matches EmptyState without the start link. A whitespace-only search matches everything.
- Sorting by return orders the rows up, flat, down.
- A load error shows the warning card and not the EmptyState.
- A `listRuns` result that is not an array counts as empty.
- Refresh fetches the list again. The page has one h1.
- The row action container wraps (`flex-wrap`).

### `T08.chat.test.tsx` (chat components rendered)

**WelcomeScreen**
- The h1 is `text-xl font-semibold`, not serif or oversized. The subtitle below it is 13px and muted.
- Quick actions form a labelled `sm:grid-cols-2` group of `rounded-lg` buttons with 16px icons and no numbering.
- A click sends a non-empty prompt. Only one button is `aria-pressed` at a time.
- Featured examples sit in a 2-column list and a click sends a prompt. The library opens with its toggle and closes on Escape.
- The category tabs switch which one is selected.
- No banned classes are rendered.

**MessageBubble**
- A user message is a `bg-muted rounded-lg px-3 py-2` bubble in a `justify-end` row. The attachment, swarm and goal chips stay inside the bubble.
- An answer is `prose prose-sm dark:prose-invert max-w-none`, and no ancestor has bubble chrome.
- Elapsed time is formatted at three boundaries: 0.2ms shows "1 ms", 2500 shows "2.5 s" and 125000 shows "2m 5s".
- An error uses danger tokens, and retry calls back with the message. There is no retry button without `onRetry`.
- An unknown type with empty content renders nothing.

**ProgressBar**
- The bar is `h-0.5` (2px) with a primary fill, and has no shadow, glow or pulse.
- `current` is clamped into `[0, total]`. Cases: -5, 15, equal to total, and 0.
- `total` of 0 or less renders nothing.
- `sm` gives `h-2`, and the aria label reaches the sr-only `<progress>`.

**ToolProgressIndicator**
- A running step is a 13px row with exactly one 16px `animate-spin` spinner.
- ok and error steps show success and danger icons, with no spinner.
- Determinate progress shows the 2px bar and a "3/12" count instead of a spinner.
- An empty list renders nothing.

**Composer**
- The textarea sits in a `rounded-lg border bg-card` container.
- Send is a primary icon button. It stays disabled for empty or whitespace input and submits `("Run it", [])`.
- There is exactly one primary button in the row. Export is not primary, and it is disabled when `canExport` is false.
- While streaming, the textarea is read-only and the stop button (`bg-destructive`) replaces send and calls `onCancel`.
- No banned classes are rendered.

**MetricsCard and RunCompleteCard**
- MetricsCard is a Card (`rounded-lg border bg-card`) with tabular values, colored success or danger by sign.
- Unknown metrics render nothing. `compact` caps the grid at 6 metrics in 3 columns.
- RunCompleteCard is Card-based and keeps the `/runs/r-9?view=dashboard` link, with no banned classes.
