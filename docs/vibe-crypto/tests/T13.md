# T13 tests: locale sync

File: `frontend/src/__tests__/vibe-crypto/T13.localeSync.test.ts` (vitest, offline, reads source and locale files from disk only; no network, no SDK).

## How to run

```
cd /home/user/vibe-trading-crypto/frontend
npx vitest run src/__tests__/vibe-crypto/T13.localeSync.test.ts
npx vitest run src/i18n
npx tsc -b
```

## Cases

### Extractor (edge cases for step 1)
The test carries its own TypeScript AST extractor of `t()` / `i18n.t()` calls; these cases pin its behaviour.
- single, double and plain template quoted keys and defaultValues
- multi-line calls, `defaultValue` before or after other options, `i18n.t`
- JS template defaultValue `` `Open (${shortcut})` `` maps to `Open ({{shortcut}})`
- template-expression and identifier keys reported as dynamic; calls without defaultValue ignored
- `format()` / `split()` not mistaken for `t()`; empty input
- real tree yields at least 100 defaultValue keys

### defaultValue keys in en.json (steps 1-2)
- every literal key is a string leaf in en.json
- en.json text equals the component defaultValue (template placeholders normalised)
- no key used with two different defaultValues
- no defaultValue key is both leaf and branch
- ChatPanel SUGGESTIONS (dynamic `t(key, { defaultValue: text })`) keys exist with the same text

### Dynamic key families (navigation.ts)
- `trade` group exists; `navigation.groups.<id>` for every group in every locale
- `layout.<id>` and `navigation.descriptions.<id>` for every item plus settings, every locale, non-empty
- `navigation.instructions.<id>` for every item except agent
- en `navigation.groups.trade` equals the sidebar fallback "Trade"
- `pageTitleKey` for `/runs/abc`, `/compare`, `/compare/a/b`, `/about`, unknown path resolves to `layout.run|compare|about|app` whose en text equals the fallback, present in all locales
- every navigation item route resolves to an existing layout key

### Parity and translation (step 3)
- exactly 11 locales on disk, matching SUPPORTED_LANGUAGES
- identical key sets in both directions per locale
- only non-empty string leaves (no arrays, numbers, null, blank)
- placeholder parity on every defaultValue key; balanced `{{ }}` everywhere
- zh-CN, ja, ko, ar, fa: no new key copied from English except product-only values (Claude, Vibe Crypto); at most 5% of new values without the locale script
- es, de, pt-BR, id, tr: no new string of four or more words copied from English
- Turkish: no new key copied except Claude, Vibe Crypto, Terminal; over a third of new strings contain Turkish letters
- product names and commands kept verbatim (Claude Code, MetaMask, MCP, Vibe Crypto, ANTHROPIC_API_KEY, `vibe-crypto mcp install`, `claude mcp add`, URLs); German hyphenated compound form `Vibe-Crypto-...` accepted
- no mojibake in any locale

### Orphans (step 4)
- removed keys (`settings.authRequired`, `authDesc`, `apiAuthKey`, `localApiAccess`, `localApiAccessDesc`, `serverApiKey`, `storedInBrowser`, `localApiKeySaved`, `runDashboard.eyebrow`, `alphaZoo.benchRunner`, `alphaZoo.headToHeadCompare`, `paper.description`) absent from every locale
- `home.*` namespace absent from every locale
- no settings key named apiAuth / authKey / localApi / sseTicket / authRequired / authDesc
- grep proof: none of the removed keys is quoted anywhere in frontend/src, and no `home.` key is built dynamically
- `agent.authRequired` kept in all locales while `lib/api.ts` still reads it

### Component key renames
- PaperRunDetail uses `paper.colSymbol` / `paper.colQty`, not `paper.symbol` / `paper.quantity`
- PaperTrading uses `paper.pageDescription`, not `paper.description`
- renamed and original manual-account keys all present in every locale; `colSymbol` text differs from `symbol`

### Copy cleanup (step 5)
- no em dash in any value, and no escaped `—` or horizontal bar in raw files
- no CJK double dash `——` in any locale (ASCII `-- Select --` placeholders predate T13 and are allowed)
- no `Vibe-Trading` / `Vibe Trading` / `VibeTrading` outside the `X-Vibe-Trading-Auth` header name (lowercase `~/.vibe-trading/` paths are real backend paths and allowed)
- new English labels are not Title Case (proper nouns excepted)
- no `01 ` counters or ` -- ` dashes in new English copy

### Formatting (step 6)
- each locale is exactly `JSON.stringify(obj, null, 2) + "\n"`, no BOM
- no duplicate keys inside one object (raw scan, JSON.parse would hide them)

### Runtime
- zh-CN, ar, tr: after `changeLanguage` and lazy bundle load, `paper.pageDescription`, `claude.suggestRuns`, `navigation.groups.trade`, `layout.compare` resolve to the locale text, not English
- `claude.open` interpolates `{{shortcut}}` in every locale
- unknown key falls back to its defaultValue
