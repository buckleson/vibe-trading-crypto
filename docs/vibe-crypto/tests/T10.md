# T10 tests: analysis pages, options components and charts

All tests are vitest, offline and deterministic. echarts is replaced with a fake that records `setOption` (or `useChartLifecycle` is stubbed), and every `api` call is a `vi.fn`. Nothing reaches the network.

## Commands (run from `frontend/`)

```
cd /home/user/vibe-trading-crypto/frontend
npx vitest run src/__tests__/vibe-crypto/T10.bannedPatterns.test.ts src/__tests__/vibe-crypto/T10.chartOptions.test.tsx src/__tests__/vibe-crypto/T10.scales.test.tsx src/__tests__/vibe-crypto/T10.pages.test.tsx
npx vitest run src/pages/__tests__/AlphaZoo.test.tsx src/pages/__tests__/ResearchLab.test.tsx src/pages/__tests__/ResearchArtifacts.test.tsx src/pages/__tests__/OptionsLab.test.tsx src/pages/__tests__/Correlation.test.tsx src/pages/__tests__/PixelOffice.test.tsx src/components/options src/components/charts
npx tsc -b
```

## Current result
336 tests across the T10 files and the existing owned tests. 335 pass and 1 fails:
- `T10.bannedPatterns.test.ts` > "ShannonPortfolio has no raw <button> left". `components/charts/ShannonPortfolio.tsx` still has two raw `<button>` elements, the "use latest" link (line 100) and the catalog "retry" link (line 104). The T10 handoff says the raw button there was replaced with `Button`, but only one was.

Not failing, but worth noting:
- `CandlestickChart.tsx` range and indicator toggles are raw `<button>`s with `font-mono` and `text-muted-foreground/50`. They are excluded from the raw-button check and listed here instead.
- The AlphaZoo catalogue is a hand-written `<table>`, not the `Table` primitive. The spec allows "Table or Card grid".
- Locale titles are "Alpha Zoo" and "Pixel Office" (title case). The page tests match case-insensitively because locale JSON is off-limits to T10.
- `OptionsPayoffChart` area fill alpha is `1F` (0.122). The test allows up to 0.125 as "0.12 rounded". The Monte Carlo P25 to P75 envelope uses `33` (0.2) on a stacked band, and stacked envelopes are allowed up to 0.2.

## Test cases

### T10.bannedPatterns.test.ts (static source audit)
Owned set: the pages AlphaZoo, ResearchLab, ResearchArtifacts, OptionsLab, Correlation and PixelOffice, plus every file in `components/options` and `components/charts`. Comment lines are ignored.
- Owned file set includes all expected files and no test files.
- Zero hits for each of these: `uppercase` class, `textTransform: uppercase`, `tracking-*`, `font-serif`, `bg-gradient-*`, CSS `*-gradient(`, `LinearGradient`/`RadialGradient`, `colorStops`, Tailwind gradient stops, `shadow-*` glow classes, `drop-shadow`, ECharts `shadowBlur`/`shadowColor`, `animate-pulse`, `animate-ping`/`animate-bounce`, literal em dash, `rounded-xl/2xl/3xl`, `text-[6..11px]`, `text-2xs`, blur glows, beige palette, purple palette, raw Tailwind palette colors, mono plus uppercase labels.
- No escaped em dash (`—`, `&mdash;`), no emoji, no 01/02/03 counters.
- No in-canvas ECharts `title: { text|show|left|top }` in charts.
- Raw hex appears only in `chartTokens.ts`.
- Every chart `fontSize:` literal is at least 11.
- Every chart that uses `tooltipBg` declares `box-shadow:none`.
- Every echarts chart reads colors from `getChartTheme`, `getPnlColors` or `tokenRgb`.
- Each page imports `@/components/ui` and renders `<Page>` and `<PageHeader>`. Pages contain no hand-written `<h1>`.
- Options components import ui primitives and contain no raw `<button>`.
- ShannonPortfolio has no raw `<button>`. **Currently fails** (see above).
- Charts other than CandlestickChart and ShannonPortfolio contain no raw `<button>`.
- OptionsChainTable uses Table primitives and tints ITM rows with `bg-muted/40`.
- VolatilitySurfaceGrid uses only `hsl(var(--primary) / a)` (no danger, success, warning or info tokens) and has a legend key.
- CorrelationMatrix diverging stops are read in the order `--danger`, `--muted`, `--primary`.
- Pixel CSS block:
  - The floor is `hsl(var(--card))` with two `hsl(var(--border) / 0.35)` grid lines and a background-size.
  - Desks are `hsl(var(--muted))`.
  - No `drop-shadow`, `filter:` or `text-shadow`.
  - `box-shadow` is used only with zero blur (pixel hair).
  - Sprite colors come from `var(--pixel-color)`.
  - The animation is turned off under `prefers-reduced-motion`, and the typing indicator is the only animated selector.
  - PixelOffice renders the indicator only when `agent.load > 0`.

### T10.chartOptions.test.tsx (runtime ECharts option audit, 15 charts)
Charts covered: AnnualReturns, AttributionCumulative, AttributionWaterfall, Candlestick, CorrelationMatrix, Distribution, Equity, MiniEquity, MonteCarloPaths, MonthlyReturnsHeatmap, OptionsPayoff, OptionsScenarioMatrix, RegimeTimeline, RollingBetaAlpha, WalkForward. Each is rendered with synthetic fixtures.

Checks run on every chart:
- At least one option is built.
- No gradient objects (`type: linear/radial`), no `colorStops`, no `gradient(` strings anywhere in the option tree.
- No visible title component.
- The tooltip uses theme `tooltipBg`/`tooltipBorder`, `borderWidth` 1, `box-shadow:none` and 12px text.
- Visible axis labels are 11 to 12px in the theme text color.
- Split lines use the theme grid color.
- Legends sit top-left with 12px text.
- Area fills are solid strings with alpha between 0.08 and 0.125 (stacked envelopes up to 0.2).

Theme and color checks:
- The series palette has 6 colors in both light and dark, and switches with the `dark` class.
- EquityChart uses `seriesPalette[0]` for equity and `downColor+1A` for drawdown.
- MiniEquityChart is up-colored when rising and down-colored when falling. With fewer than 2 points it builds no chart.
- OptionsPayoff keeps the pnl-colors profit and loss colors under the zh locale.
- Candlestick follows the locale convention: green up in en, red up in zh.
- No hex in any option falls outside the theme, palette or pnl colors (or #111111 and #ffffff).

Edge cases:
- 11 charts render with empty data without throwing.
- CorrelationMatrix with no labels shows the empty text and creates no echarts instance.
- Charts dispose their instance on unmount.

### T10.scales.test.tsx
chartTokens:
- `tokenRgb` parses `H S% L%`, parses with `/ alpha`, falls back when the token is missing or malformed, and handles black, white and grey.
- `rgbCss` produces rgb or rgba.
- `mixRgb` returns the endpoints and rounds the midpoint.
- `luminance` covers its bounds and is monotonic.
- `contrastText` gives dark text on light colors and white text on dark colors.

CorrelationMatrix:
- visualMap runs from -1 to 1 with the colors [danger, muted, primary] taken from CSS tokens. It falls back to defaults when the tokens are missing.
- Cell label contrast is dark text for 0 and 0.05, white text for ±1.
- Out-of-range values are clamped for color but keep their raw value.
- Values are rounded to 4 decimal places, labels show 2, at 12px.
- In-cell labels show at 8 assets and are hidden at 9 or more.
- Ragged or missing rows render as a muted "-".
- No title, and the tooltip has a 1px border with no shadow.
- Empty input shows the message.
- Tooltip names are HTML-escaped.

VolatilitySurfaceGrid:
- Cells use the primary hue only, with alpha 0.10, 0.46 and 0.82 for low, mid and high, increasing in that order.
- `primary-foreground` text appears only when ratio > 0.62.
- A flat surface uses the mid tone and does not divide by zero.
- The legend shows min and max with 5 monotonic swatches.
- A missing point shows "N/A" with no color.
- Observed points get a primary ring and interpolated points do not.
- Before compute, there is no table and no legend.
- The table sits in an `overflow-x-auto` wrapper.

### T10.pages.test.tsx
- Page headers: each of the six pages has a single h1 with the expected title (case-insensitive).
- AlphaZoo browse:
  - Lists alphas with detail links and calls `listAlphas({limit:1000})`.
  - Search is case-insensitive and trimmed, and matches nickname as well as id.
  - The zoo filter narrows the list. A search with no match shows the empty row.
  - Selecting two alphas builds `/alpha-zoo/compare?ids=a,b`. Selecting one US alpha builds the bench URL with `universe=sp500`.
  - A load failure calls `toast.error` and leaves the table empty.
  - The table scrolls inside its wrapper.
  - The bench and compare sub-routes render their own views.
- ResearchArtifacts: shows EmptyState when there are no artifacts, and an alert when loading fails.
- PixelOffice:
  - The typing indicator appears only when load > 0. With no active agent there is no animated element.
  - `--pixel-color` carries each agent's color, and the sprites are aria-hidden with no filter.
  - The floor uses the pixel-office-floor class with a token border and no shadow, gradient or large radius.
  - Clicking a desk selects that assignee, and create sends `assigned_to`.
  - With zero agents, the floor renders empty.
  - While loading, a status line shows and no fabricated floor appears.
