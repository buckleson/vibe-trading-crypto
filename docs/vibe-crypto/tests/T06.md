# T06 tests: Claude chat panel (Claude Agent SDK + app MCP tools)

Files:
- `agent/tests/vibe_crypto/test_T06.py` (132 cases with parametrisation): service, routes, dependency declarations.
- `frontend/src/__tests__/vibe-crypto/T06.claudeChat.test.ts` (31 cases): `lib/claudeChat.ts`.
- `frontend/src/__tests__/vibe-crypto/T06.chatPanel.test.tsx` (45 cases): ChatPanel, ChatMessage, ToolCallRow, ChatComposer, store.

All tests are offline and deterministic. The Claude Agent SDK is never called for real: Python tests replace `src.claude_chat.service._query` (or `claude_agent_sdk.query`) with fake async generators that yield real SDK dataclasses; frontend tests stub `fetch` and mock `@/lib/api` / `@/lib/claudeChat`. `get_runtime_root` is redirected to `tmp_path`. Implementation code was not modified.

## Run

```

cd /home/user/vibe-trading-crypto && python -m pytest agent/tests/vibe_crypto/test_T06.py -q

cd /home/user/vibe-trading-crypto/frontend && npx vitest run src/__tests__/vibe-crypto/T06 src/components/claude src/lib/__tests__/claudeChat.test.ts
```
