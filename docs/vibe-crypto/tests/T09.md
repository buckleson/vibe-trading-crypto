## T09.bannedPatterns.test.ts (static source audit, 33 tests)
Owned files: the 4 pages plus every `.tsx` in `components/settings` and `components/portfolio`. Comment lines are ignored.
- Owned file set includes ClaudeSettings, SecretInput and all restyled components; no test files.
- Zero hits for: `uppercase`, `tracking-wide*`, `font-serif`, gradient bg and stops, glow shadows (sm/md/xl/2xl/inner/arbitrary/colored), `animate-pulse`, `animate-ping`, literal em dash, `rounded-xl/2xl/3xl`, `text-[6..11px]`, `text-2xs/xxs`, blur, `text-positive` (undefined token), beige palette.
- `shadow-lg` only in ModelPicker popover and the ConnectionCenter / PortfolioSourceEditor drawers (BRIEF allows popovers/dialogs).
- No escaped em dash (`—`, `&mdash;`), no emoji, no 01/02/03 counters, no purple/violet/pink utilities, no raw Tailwind palette colors, no raw hex literals.
- Non-ASCII limited to middle dot, masking bullet, en dash, and CJK axis units.
- Each page imports `@/components/ui` and renders `Page` + `PageHeader`; Settings is `narrow`, the others `wide`.
- Portfolio and Scheduled use the `Table`/`THead` primitives, no raw `<table>`.
- Settings has no `apiAuthKey`/`@/lib/apiAuth` usage (ADR 0002).
- ClaudeSettings imports `getClaudeStatus` from `@/lib/claudeChat` and has no raw `fetch(`.

- Settings save errors are reported by toast only. The spec asked for "errors inline with role=alert"; only load errors are inline. Tests assert current toast behaviour.
- Runtime h1 reads "Live / Paper Runtime Status" (existing locale), not "Runtime".
- Scheduled title locale is "Scheduled Research" (title case) and `scheduled.empty` locale copy contains an em dash ("No scheduled runs yet — create one above."), which reaches the UI. Locale JSON is outside T09; the locale sync task should fix both.
- 390px: verified only structurally (tables in `overflow-x-auto`, sub-nav hidden below lg, command box scrolls). No browser layout measurement in jsdom.
