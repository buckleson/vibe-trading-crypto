# T14 tests: README, guides, assets, handoff and checklist

File: `agent/tests/vibe_crypto/test_T14.py` (256 cases with parametrisation). Offline and deterministic: the tests read repo files, import `mcp_server` and `api_server` in process to list registered MCP tools and FastAPI routes, run the local `vibe-crypto --help`, `serve --help`, `mcp --help` and `mcp config` (no network), and read `git show HEAD:guides/news.md` (skipped when git or the blob is missing).
