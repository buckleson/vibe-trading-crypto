# T05 tests: paper trading UI (strategy runs, manual accounts tab, start dialog)

All tests are vitest in jsdom. They are offline and deterministic, with no network, no backend and no Anthropic SDK.
- `T05.paperRuns.test.ts` stubs global `fetch`.
- `T05.paperTradingUI.test.tsx` mocks `react-i18next`, `@/lib/api`, `paperRunsApi` in `@/lib/paperRuns` (the real formatters are kept) and `EquityChart`.

`document.visibilityState` is stubbed per test. The tests that depend on timing use vitest fake timers. No implementation code was changed.

## Test cases

### `frontend/src/__tests__/vibe-crypto/T05.paperRuns.test.ts` (client and helpers)

Routes:
- `list` is a GET to `/api/paper-runs` with no body and returns the parsed array.
- `create` is a POST to `/api/paper-runs` with a JSON body and a JSON content-type header.
- `create` with only `run_id` does not add `label` or `initial_cash`.
- `get` is a GET to `/api/paper-runs/<id>`.
- `refresh` and `stop` are POSTs to `/refresh` and `/stop`, with no body.
- `remove` is a DELETE and returns `{deleted}`.
- Ids are encoded in all four id routes. The test ids are `a/b`, a space, `q?x=1#h`, `..` and unicode.

Errors:
- A 422 with a string detail rejects with that message.
- A 422 with a pydantic list detail rejects with `loc: msg`.
- A 404 rejects with the detail and `status`.
- An empty 200 body resolves to `{}`.
- A non-JSON (HTML fallback) 200 rejects.
- A network failure propagates.

Timeout:
- `refresh` is still pending at 170 s and is aborted with `request_timeout` by 181 s.
- `get` keeps the shorter default timeout.

Helpers:
- `formatNumber` always shows 2 decimals.
- `formatPercent` scales by 100, adds a sign only when asked, and adds no `+` to 0.
- `formatSigned` signs positive values.
- `tone` and `toneClass` treat 0, null and undefined as neutral.
- `relativeTime` boundaries:
  - null or an invalid date gives null.
  - Under 30 s, or a time in the future (clock skew), gives "just now".
  - Then "3 min ago" and "59 min ago".
  - 60 min gives "1 h ago" and 23 h gives "23 h ago".
  - 24 h gives "1 d ago".
  - The default `now` is the current clock.

### `frontend/src/__tests__/vibe-crypto/T05.paperTradingUI.test.tsx` (page)

Page shell and tabs:
- The title, description and header "Start paper run" render.
- The Strategy runs tab is selected by default (`aria-selected`), and only the paper runs list is loaded.
- `?tab=bogus`, `?tab=` and `?tab=MANUAL` all fall back to Strategy runs.
- Clicking Manual accounts sets `?tab=manual`, keeps `?run`, and loads the manual accounts. Clicking back removes `tab`.
- `?tab=manual` loads manual accounts and does not load paper runs.
- The header button on the manual tab switches to runs and opens the dialog.

Run list:
- Loading shows at least 3 skeleton rows and no empty state; they are gone once the list loads.
- The empty state shows the spec copy, and its action opens the dialog.
- A list load failure shows an inline alert.
- A row shows "BTC-USDT, ETH-USDT on 1D", the equity, and "Updated 3 min ago".
- Badge tones:
  - Active is info and Stopped is neutral.
  - "Waiting for data" is warning and "Error" is danger.
  - The `ok` state shows no state badge.
- Return colors:
  - A gain shows `+` and `text-success`.
  - A loss shows `text-danger`.
  - Zero shows no color and no sign.
- A null summary shows `n/a`, no return, and no "Updated" line.
- With no selection, the detail area shows a prompt and `get` is not called.
- The selected row has `aria-current`.

Run detail:
- The header shows the label, "Started <toLocaleString>" and "Counts from 2026-01-01 12:00:00".
- The six stats show the right values and tones: negative P&L and Return are red, Max drawdown, Sharpe to 2 decimals, and the Trades count.
- The chart receives the equity data, the positions table shows Weight %, and the footnote is present.
- Positive P&L is green with `+`.
- Equity uses the BRIEF hero style. **This test fails; see Results.**
- With a null summary, all six stats read `n/a`, and the empty texts "No open positions" and "No trades yet" show.
- With one equity point, the empty curve message shows instead of the chart.
- The waiting banner shows the exact copy with `evaluation_start`.
- The error banner shows `last_error` in danger. Its Refresh button refreshes, and the banner clears afterwards.
- A null `last_error` shows the "Refresh failed." fallback.
- A `get` failure shows an alert.
- Trades:
  - Rows keep the API order.
  - The side badges read Sell and Buy.
  - P&L and Return % are colored by sign.
  - Entry rows show no `null` or `NaN`.
- Exactly 50 trades show with no "Show all" button.
- 51 trades show 50 rows, and "Show all 51" expands to all 51.
- A stopped run shows no Stop button but still shows Refresh and Delete.

Refresh behaviour:
- A run refreshed 30 s ago is not refreshed on open.
- A run refreshed 2 min ago is refreshed exactly once on open.
- A stale run that is stopped is not refreshed.
- A refreshed run updates its equity and return in the list.
- A failed manual refresh shows an inline error and keeps the stats and chart.
- No refresh happens at 4:59. One happens at 5:01 and a second at 10:01.
- No interval refresh happens while the tab is hidden. It resumes once the tab is visible again.
- A stopped run gets no interval refresh.
- The interval is cleared on unmount.
- Switching runs reloads the detail, updates `?run`, and only the new run's interval fires.

Stop and delete:
- The stop confirmation uses the spec copy, and Cancel makes no API call.
- Stopping changes the list badge to Stopped.
- A stop failure shows an alert and keeps the Stop button.
- Delete can be cancelled by the Cancel button or by Escape, and no call is made.
- Delete removes the run, clears `?run` and keeps the other runs.
- Deleting the last run shows the empty state.
- A delete failure shows an alert and keeps `?run`.

Start dialog:
- It has `role=dialog` and `aria-modal`, and its accessible name is "Start paper run".
- The select has focus on open, and the backdrop is `bg-foreground/20`.
- Only runs with status `success` or a `total_return` are listed, from `listRuns(50)`.
- Option text looks like `r1 (BTC-USDT, ETH-USDT, 25.00%)`. A failed run that has a return is included, and the first option is selected by default.
- The name placeholder follows the selected run's codes.
- Starting cash is a `type=number` field with the hint.
- With no usable backtests, the hint shows, there are no options, and submit is disabled.
- A `listRuns` failure shows an alert inside the dialog.
- Escape closes the dialog without creating a run.
- A backdrop click closes it, and a click inside the card does not.
- Cancel closes it.
- With the name and cash empty, the request omits `initial_cash` and sends the label "<codes> paper".
- A name with surrounding spaces is trimmed, and cash is sent as a number.
- On success:
  - The dialog closes.
  - The new run is prepended above the existing ones.
  - `?run=new1` is set.
  - `refresh("new1")` is called.
- On a 422:
  - The message shows in the dialog.
  - The dialog stays open.
  - The list and `?run` are unchanged.
  - Submit is enabled again for a retry.

`?from_run`:
- An id that is already in the list is preselected without a duplicate option, and `from_run` is removed from the URL.
- An unknown id is added as the first option and preselected.
- On the manual tab, it switches to runs and removes both `from_run` and `tab`.
- An existing `?run` is kept.
- Submitting sends `{run_id: <preset>}`.

Slop ban list (static and rendered):
- Each T05 source file has no em dash, `uppercase`, `tracking-widest`, gradients or purple, `animate-ping`, or 01/02 counters.
- No file imports `react-router-dom`.
- The rendered detail text has no em dash.

## Notes for the developer

- **Hero number:** to fix the failing test, give the Equity value `text-[32px] font-semibold tabular-nums`. For example, pass a className through `Stat`, or render Equity outside `Stat`.
- **Default label:** when Name is empty, the dialog sends "<codes> paper" as the label. The spec only asked for this as a placeholder. The tests assert the current behaviour, so update the assertion if the label is dropped.
