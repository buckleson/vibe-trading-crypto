# T08 handoff: Page redesign A (Agent, RunDetail, Compare, Reports)

## Changed
- Pages: `Agent.tsx` (centered max-w-3xl column, ui Buttons/Skeleton, no backdrop blur), `RunDetail.tsx` (Page, PageHeader, ui Tabs, Table primitives, EmptyState, "Run on paper" link), `Compare.tsx` (Page, Field/Select, Card, Table), `Reports.tsx` (Page, Table, Badge, Input/Select, EmptyState).
- Chat components: WelcomeScreen (no serif, 2-column prompt grid), MessageBubble (rounded-lg user bubble, unboxed prose answer, no serif, static caret), ActivityLine and ToolProgressIndicator (16px icons, 13px rows, spinner only), Composer (Button primitives, bordered card container), ProgressBar (2px), MetricsCard and RunCompleteCard (Card), GoalPanel, MandateProposalCard (numbered badges removed), ScheduledResearchProposalCard, SwarmStatusCard (pulsing dots replaced by spinner), RunnerStatus, SwarmDashboard, LiveRuntimePanel, ModelRuntimeBar, RunnerBudgetControls: banned patterns removed, palette colors mapped to tokens.
- Run components: RunCard (Card, Table), LlmUsagePanel (Table), PositionsTab (radius, purple/pink removed from chart palette).
- Tests updated: RunDetail (run label, radius, new "Run on paper" href test), RunDetail.usage, Compare (heading size), MessageBubble(.math), ProgressBar, SwarmStatusCard(.usage), SwarmDashboard.

## Behaviour notes
- "Run on paper" is a router Link to `/paper-trading?from_run=<encoded runId>`, shown when status is success or an equity curve exists.
- Null placeholders changed from an em dash to "-" (usage tables, mandate, runner status, swarm tokens). Chat tool names, SSE, store, test ids unchanged.
- Run header text is now "Run <id>" (was "RUN <id>").
- Streaming caret no longer pulses.

## Known leftovers
- Composer keeps a single row (attach, input, export, send) instead of a separate footer row.
- Inner tab content still has its own `p-4` wrappers (double padding with Page); harmless, tighten in the polish pass.
- Remaining raw hex is intentional: chart fallbacks in Compare (token values) and series palette/CASH_COLOR in PositionsTab (ECharts needs literal colors).
- Comment-only em dashes were replaced too.
- 390px and light/dark screenshots: not measured (no browser run in this task).

## Round 1 fixes

- Compare.tsx: `fmt()` and `diffStr()` returned an escaped em dash as the missing-value placeholder. Both now return "-", matching RunDetail.tsx.
