# T02 handoff: remove app authentication

## Changes
- `agent/src/api/security.py`: removed SSE tickets, API key helpers, `SHARED_KEY_SUBJECT`, HTTPBearer. Added `_require_local_request`; `require_auth`, `require_event_stream_auth`, `require_local_or_auth`, `require_settings_write_auth` now take only `request`. `_require_shutdown_authorization(*, request)`.
- Deleted `agent/src/api/auth_routes.py`; `api_server.py` re-exports trimmed.
- `agent/src/api/system_routes.py` (NOT in owned list, minimal edit): dropped `_security`/`_configured_api_key`, `/docs` and `/redoc` now served to local clients, shutdown guard call.
- `server_cli.py` warning; `env_schema.py`/`accessor.py` (`api_auth_key`, `vibe_trading_api_key` and alias validator removed); `alpha_bench_tool.py` HMAC key is the persisted machine key only; `cli/_legacy.py` and `cli/main.py` send no Authorization; `.env.example`; compose/Dockerfile already had 127.0.0.1 publish + `VIBE_TRADING_TRUST_DOCKER_LOOPBACK=1`, no change needed.
- Frontend: deleted `lib/apiAuth.ts` + test; `api.ts`, `useSSE.ts` (direct `EventSource(url)`), `Settings.tsx` (key section removed), `vite.config.ts` (`/auth` removed). `api.swarmSseUrl`/`alphaBenchStreamUrl`/`alphaCompareStreamUrl` now return plain strings (`useAlphaJob.ts` still `await`s them, harmless).
- Electron: `main.ts` no key/no header injection; `backend-manager.ts` no `apiAuthKey`, `delete childEnvironment.API_AUTH_KEY`; scripts and THREAT_MODEL.md updated.
- Tests: deleted `test_auth_precedence.py`, `test_security_auth_api.py`; trimmed `test_sse_ticket_and_headers.py`; new `agent/tests/test_local_guard.py` (8 tests); rewrote auth cases in upload/settings/system/regime/playbooks/openbb/cli tests. Not-owned test edits: `test_principal.py` (local guard tests, local SHARED_KEY_SUBJECT constant), `test_connection_routes.py` (IBKR endpoint cross-site 403).
