# T05 handoff: paper trading UI

## Files
- frontend/src/lib/paperRuns.ts: typed client for the six /api/paper-runs routes (refresh uses a 180 s timeout) plus format helpers (formatNumber, formatPercent, formatSigned, toneClass, relativeTime).
- frontend/src/pages/PaperTrading.tsx: Page + PageHeader + Tabs. `?tab=manual` selects Manual accounts (default Strategy runs), `?run=<id>` selects a run, `?from_run=<id>` opens the start dialog with that run preselected and is then removed.
- frontend/src/components/paper/: ManualAccounts (old page moved, restyled, same behaviour and translation keys), PaperRunsView (list + layout), PaperRunDetail (stats, banners, chart, tables, refresh/stop/delete, auto refresh), StartPaperRunDialog.
- Tests: lib/__tests__/paperRuns.test.ts, pages/__tests__/PaperTrading.test.tsx (now renders at ?tab=manual), pages/__tests__/PaperTradingRuns.test.tsx.

## Behaviour notes
- Detail refreshes on open if the run is active and last_refreshed_at is null or older than 60 s, then every 5 minutes while active and the page is visible. Refresh errors show inline and keep previous data.
- Imports use `react-router` (not react-router-dom) and `@/components/common/ConfirmDialog` / `Skeleton` directly (no common index).
- Start dialog defaults the run name to "<codes> paper" when left empty.
- New strings use `t('paper.<key>', { defaultValue })`; locale JSON untouched.
