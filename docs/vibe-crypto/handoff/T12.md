# T12 Wallet connect (ADR 0007)

Read-only EIP-1193 wallet button in the top bar. No signing, no transactions, no backend calls, no new dependencies.

## Files
- `frontend/src/lib/wallet.ts`: provider type (declares `window.ethereum` locally), `getProvider`, `connectWallet`, `getAccounts`, `getChainId`, `getBalanceWei`, bigint `formatUnits`, `shortAddress` (U+2026), `CHAIN_INFO`/`chainLabel`, `isUserRejection`.
- `frontend/src/components/wallet/useWallet.ts`: state and listeners. Storage flag `vc-wallet-connected`. Restores via `eth_accounts` only when the flag is '1'; `accountsChanged` and `chainChanged` subscribed, removed on unmount.
- `WalletPopover.tsx`: `NoWalletPopover` (browser and desktop variants) and `ConnectedPopover` (address+copy, chain badge, balance, refresh, forget). Closes on Escape and outside click, focuses itself on open.
- `WalletButton.tsx`: replaces the T03 stub, still exports only `WalletButton`.
- Tests: `lib/__tests__/wallet.test.ts`, `components/wallet/__tests__/WalletButton.test.tsx`.

## Outside owned paths
`src/__tests__/vibe-crypto/T03.pages.test.tsx`: removed the "WalletButton renders nothing" stub assertion (no longer true). The export-names assertion is kept and still passes.

## Notes
- Strings use `t('wallet.*', { defaultValue })`; locale JSON untouched (T13 should add the `wallet.*` keys: connect, declined, noWalletTitle, noWalletText, getMetaMask, desktopNote, copyLink, linkCopied, popoverLabel, copyAddress, addressCopied, refresh, readOnly, forget, forgetNote).
- Backend CSP (`script-src 'self'`) should not block extension-injected providers in current MetaMask (MV3 main-world injection). Not verified in a real browser here.
- Electron renderer has no extensions, so desktop always shows the "open in a browser" explanation.
