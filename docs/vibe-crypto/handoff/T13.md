# T13 Locale sync

All 11 locales (en, zh-CN, ja, ko, ar, fa, es, de, pt-BR, id, tr) now share one key set, with every literal `t('key', { defaultValue })` in `frontend/src` present in `en.json`.

## Added: 151 keys per locale
Namespaces: `claude.*` (chat panel, dock, suggestions), `paper.*` (strategy runs view, start dialog, detail), `settings.claude*` / `settings.nav*` / `settings.desktop*` / `settings.sections` / `settings.hideSecret` / `settings.showSecret`, `wallet.*`, `terminal.*`, `about.*`, `layout.run|compare|app|selectLanguage`, `navigation.groups.trade`, `options.surface.legend`, `reports.run|actions`, `runDetail.runOnPaper|sections`, `scheduled.newSchedule|col*`.
Placeholders (`{{name}}`, `{{date}}`, `{{count}}`, `{{when}}`, `{{url}}`, `{{shortcut}}`) are identical in every locale. `claude.close` / `claude.open` use `{{shortcut}}` (the component's own defaultValue is a JS template with the shortcut already inlined, so en.json is authoritative).
Product names (Vibe Crypto, Claude, Claude Code, MetaMask, MCP) and the `vibe-crypto mcp install` / `ANTHROPIC_API_KEY` snippets are verbatim.

## Component key renames (3 edits, collision with existing en.json keys that had different text)
- `components/paper/PaperRunDetail.tsx`: `paper.symbol` -> `paper.colSymbol` (existing `paper.symbol` is "Symbol (e.g. AAPL.US)", a manual-account placeholder), `paper.quantity` -> `paper.colQty` (existing is "Quantity").
- `pages/PaperTrading.tsx`: `paper.description` -> `paper.pageDescription` (old key text described the manual accounts only). Old `paper.description` removed from all locales.
Not renamed: `settings.gildataTokenDesc` still holds the older, longer en.json text; the component defaultValue is only a fallback and never shows.

## Removed (all locales, after grep proof of zero references including dynamic families)
`settings.authRequired`, `settings.authDesc`, `settings.apiAuthKey`, `settings.localApiAccess`, `settings.localApiAccessDesc`, `settings.serverApiKey`, `settings.storedInBrowser`, `settings.localApiKeySaved` (auth removal), `home.*` (20 keys, old Home page replaced by the About page), `runDashboard.eyebrow`, `alphaZoo.benchRunner`, `alphaZoo.headToHeadCompare`, `paper.description` (renamed).
Kept on purpose: `agent.authRequired` is still read by `lib/api.ts` (`AUTH_REQUIRED_MESSAGE`, used in `pages/Agent.tsx`). That code is outside T13 paths; if it is deleted later, drop the key too.
Other keys with no literal reference (about 60, e.g. `settings.llmBackend`, `scheduled.delivery_*`) were left: several are dynamic families and the rest predate this fork.

## Copy cleanup
- Every em dash in locale values replaced (comma, colon or period chosen per string in en.json, and the same choice mirrored in the other locales with locale punctuation, `，` `：` `。` for zh-CN and ja). Double dashes in zh-CN, ja and ko removed. The remaining `X-Vibe-Trading-Auth` header name is a real backend header (`agent/src/channels/websocket.py`) and stays verbatim. `shannon.styleNote` now says "shown as a dash" instead of embedding the glyph.
- Sentence case: all keys added in this task are sentence case. Existing upstream Title Case English labels (about 150, e.g. `settings.llmSettings`, `runDetail.runCard`, `runtime.title`) were NOT converted: an automated conversion broke 104 assertions in other developers' page and component tests that match the Title Case text (`getByText("LLM Settings")` and similar). Converting them needs those tests updated in the same change. The converter is `/tmp/claude-0/i18n/sentence.mjs` (outside the repo, dry run by default, `apply` writes en.json).
- `i18n.test.ts`: added "Claude", "Vibe Crypto", "Terminal" to the Turkish shared-terms list (identical in Turkish).

## Outside owned paths
`components/settings/__tests__/ChannelSettings.test.tsx` lines 515 and 843: two assertions matched the old em dash copy, updated to the new punctuation.

## Not covered
- Component `defaultValue` strings in `.tsx` files were not edited (outside owned paths); where they differ from en.json, en.json wins at runtime.
- Turkish and other existing locale strings that were already English or garbled before this task were not touched.
- Spot check in the running app: not measured.
