## Storage
`<runtime_root>/paper-runs/<id>/`: paper_run.json, source_config.json, config.json (rewritten each refresh), code/*.py, artifacts/ (deleted and regenerated each refresh).

## REST contract
Reads need `require_auth`, writes `require_settings_write_auth` (same names as before). Errors: 404 `{"detail":"Paper run not found"}`, 422 `{"detail":"<message>"}`.

`POST /api/paper-runs` body (extra fields rejected):
`{"run_id":"abc123","label":"optional, max 80","initial_cash":10000,"warmup_days":180}` (all but run_id optional) returns the run document:
```json
{"id":"3f9a1c0b7d2e","label":"BTC-USDT paper","source_run_id":"abc123","codes":["BTC-USDT"],
 "source":"okx","interval":"4H","initial_cash":10000.0,
 "started_at":"2025-06-10T10:30:00+00:00","evaluation_start":"2025-06-10T12:00:00",
 "warmup_start":"2024-12-12","status":"active","stopped_at":null,
 "last_refreshed_at":null,"state":"waiting","last_error":null,"summary":null}
```
`GET /api/paper-runs` returns a list of run documents, newest first.

`GET /api/paper-runs/{id}`, `POST .../refresh` (recomputes via the backtest engine, can take seconds), `POST .../stop` return detail:
```json
{"run": {"...document, state ok after refresh...",
         "summary":{"equity":11000.0,"pnl":1000.0,"total_return":0.1,"max_drawdown":-0.0097,
                    "sharpe":1.5,"trade_count":2,"bars":5,"as_of":"2025-06-15 00:00:00"}},
 "equity":[{"time":"2025-06-11 00:00:00","equity":10000.0,"drawdown":0.0}],
 "trades":[{"time":"...","symbol":"BTC-USDT","side":"sell","price":110.0,"qty":1.0,"pnl":10.0,
            "return_pct":0.1,"event":"exit","reason":"sig"}],
 "positions":[{"symbol":"BTC-USDT","weight":0.5}]}
```
Trades newest first; NaN becomes null; lists are empty until a successful refresh. `state`: `waiting` (fewer than 2 forward bars, UI shows "waiting for the first bars"), `ok`, `error` (`last_error` up to 500 chars). `DELETE .../{id}` returns `{"deleted":true}`.

Stopped runs freeze `end_date` at the stop date; refresh after stop still works.
