# Vibe Crypto: task checklist

Source of truth for the fork work. One section per task; task ids match the
developer specs. Tasks in the same wave run in parallel and own disjoint paths.
Developers do not edit this file; they write `docs/vibe-crypto/handoff/<ID>.md`
and T14 ticks the boxes at the end.

Decisions: `ADR/0001` to `ADR/0007`. Design brief: `cook/BRIEF.md`.
